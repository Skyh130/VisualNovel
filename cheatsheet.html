📖 Ren'Py 치트시트

코딩하다 막히면 여기부터 · 코드는 직접 손으로 씁니다
💡 이렇게 쓰세요 코드는 보고 직접 타이핑하는 것이 가장 빨리 늡니다. 복사 버튼은 오타 때문에 계속 막힐 때만 쓰세요. 막히면 치트시트 → 공식 문서 → 친구 → 선생님 순서로 물어봅니다.

1. 기본 뼈대

define y = Character("유나", color="#f0a0a0")
define m = Character("나")

label start:
    scene bg_school
    y "안녕? 처음 보는 얼굴인데."
    "교실 안이 조용해졌다."
    return
  • define … Character() : 말하는 사람을 미리 정의
  • label 이름: : 하나의 장면 묶음. 분기의 단위
  • y "…" : 유나의 대사
  • "…" : 이름 없이 나오면 나레이션
  • return : 게임 종료 또는 호출 지점으로 복귀

2. 화면 연출

scene bg_school with fade
show yuna happy at left
show minsu at right
hide yuna with dissolve
pause 1.0
  • scene : 배경 교체 (기존 화면 전부 정리)
  • show : 캐릭터 세우기 / 표정 교체
  • at left, at right, at center : 서 있는 위치
  • with fade, with dissolve : 전환 효과
  • pause 1.0 : 1초 멈춤

3. 선택지와 분기

menu:
    "말을 건다":
        $ affection += 1
        jump talk_scene
    "그냥 지나친다":
        jump ignore_scene
  • menu: : 선택지 화면을 띄움
  • 선택지 아래 들여쓰기한 줄이 그 선택의 결과
  • jump 라벨명 : 해당 label로 이동 (돌아오지 않음)
  • call 라벨명 : 다녀온 뒤 return으로 되돌아옴

4. 변수와 조건 분기

default affection = 0
$ affection += 1

if affection >= 5:
    jump end_true
elif affection >= 2:
    jump end_normal
else:
    jump end_bad
  • default : 게임 시작 시 변수의 초기값 (파일 맨 위에)
  • $ : 파이썬 한 줄 실행. 값 바꿀 때 사용
  • if / elif / else : 조건에 따라 다른 곳으로 분기
  • 엔딩 조건은 넉넉한 값부터 위에서 아래로 검사

5. 사운드

play music "bgm.ogg" fadein 1.0
play sound "door.ogg"
stop music fadeout 1.0
  • music : 계속 반복되는 배경음악
  • sound : 한 번만 나는 효과음
  • fadein / fadeout : 자연스럽게 커지고 작아짐
  • 파일은 game/audio 폴더에 넣습니다

6. 디버깅 (혼자 문제를 찾는 법)

$ renpy.notify(str(affection))
  • 지금 변수 값이 얼마인지 화면 구석에 띄워줍니다
  • 분기가 이상할 때 의심되는 곳마다 넣어보세요
  • 완성 후에는 반드시 지웁니다

⚠️ 자주 나는 에러 3종 — 오류의 80%는 이 셋입니다

들여쓰기 오류 (Indentation)

탭과 스페이스를 섞어 쓰면 발생합니다. 스페이스 4칸으로 통일하세요. label, menu, if 아래 줄은 반드시 한 단계 더 들여씁니다.

라벨명 오타

jump ch1_schol 처럼 label 이름의 철자가 맞지 않는 경우입니다. 정의한 label 이름을 그대로 복사해서 붙여넣는 습관을 들이세요.

이미지 파일명 불일치

show yuna happy 는 yuna happy.png 라는 이름의 이미지를 찾습니다. images 폴더의 실제 파일명, 확장자, 대소문자가 모두 일치하는지 확인하세요.

📚 더 알아보기 5~10회차에 실제로 막히는 것들입니다. 필요할 때 찾아보세요.

7. 프로젝트 폴더 구조 추가

내작품/
  game/
    script.rpy      ← 대본을 쓰는 곳
    options.rpy     ← 제목·글꼴·색 설정
    images/         ← 배경과 캐릭터 그림
    audio/          ← 음악과 효과음
    gui/            ← 화면 꾸미기 (건드리지 않아도 됨)
  • 그림은 game/images, 소리는 game/audio에 넣습니다
  • 파일 이름은 영어 소문자와 밑줄만 쓰세요. 한글·띄어쓰기는 에러의 원인입니다
  • images/bg_school.png를 넣으면 대본에서 scene bg_school
  • 회차 끝나기 전에 내작품 폴더 전체를 업로드합니다

8. 그림에 짧은 이름 붙이기 추가

image bg school = "images/bg_school.png"
image bg school night = "images/bg_school_night.png"
image yuna happy = "images/yuna_happy.png"
image yuna sad = "images/yuna_sad.png"

label start:
    scene bg school
    show yuna happy
  • image 이름 = "파일 경로" : 긴 파일명에 부르기 쉬운 이름을 붙입니다
  • 띄어쓴 이름은 show yuna happy처럼 그대로 씁니다
  • 이름을 안 붙이면 파일명 그대로 찾습니다 (에러 3종 중 하나의 원인)
  • 같은 배경을 낮·노을·밤으로 색만 바꿔 다시 쓰면 그림 부담이 크게 줄어듭니다

9. 대사 안에 따옴표·강조 넣기 추가

y "그때 네가 \"괜찮아\"라고 했잖아."
m "{i}그럴 리가 없어.{/i}"
m "{b}절대{/b} 안 돼."
m "한 박자 쉬고{w} 이어서 말한다."
m "여기서 줄을 바꿉니다.{p}다음 줄입니다."
  • \" : 대사 안에 큰따옴표를 넣을 때 (그냥 " 를 쓰면 에러)
  • {i}…{/i} 기울임 · {b}…{/b} 굵게
  • {w} : 클릭할 때까지 잠깐 멈춤
  • {p} : 클릭하면 줄을 바꿔 이어서 표시

10. 조건이 붙은 선택지 추가

default affection = 0
default knows_secret = False

menu:
    "역까지 쫓아간다":
        jump run_station

    "이름을 부른다" if affection >= 2:
        jump call_name

    "비밀을 말한다" if knows_secret:
        jump tell_secret
  • 선택지 뒤에 if 조건을 붙이면 조건이 맞을 때만 보입니다
  • 7회차에서 변수를 배운 뒤에 쓰면 이야기가 훨씬 살아납니다
  • 참·거짓 변수는 True / False (첫 글자 대문자)

11. 같은 장면 여러 번 쓰기 (call) 추가

label start:
    call morning_scene
    "1교시가 시작됐다."
    call morning_scene
    "이번에도 똑같은 아침이다."
    return

label morning_scene:
    scene bg school
    "교문 앞에서 종소리가 들린다."
    return
  • call은 다녀온 뒤 부른 자리로 돌아옵니다
  • jump는 가서 돌아오지 않습니다. 이 차이가 핵심입니다
  • '만약 그때' 주제처럼 같은 하루를 반복할 때 아주 유용합니다

12. 타이틀·글꼴 바꾸기 (options.rpy) 추가

## game/options.rpy 안에서

define config.name = _("세 번째 화요일")
define gui.show_name = True

## game/gui.rpy 안에서 (글꼴)
define gui.text_font = "fonts/NanumGothic.ttf"
define gui.text_size = 24
  • config.name : 타이틀 화면과 창에 뜨는 작품 이름
  • 글꼴 파일은 game/fonts 폴더에 넣고 경로를 적습니다
  • 한글이 네모(□)로 보이면 한글을 지원하는 글꼴로 바꿔야 합니다 (눈누에서 무료 한글 폰트)
  • 8회차에 작품 분위기에 맞춰 정합니다. 그 전에는 기본값으로 두세요

13. 세이브·스킵은 만들지 않습니다 추가

  • Ren'Py가 기본으로 만들어 줍니다. 직접 만들 필요가 없습니다
  • 저장·불러오기, 스킵(Ctrl), 되감기(마우스 휠 위), 자동 진행 모두 이미 들어 있습니다
  • 8회차에는 잘 되는지 확인만 하면 됩니다

14. 배포 빌드 만들기 추가

Ren'Py 런처 → 내 작품 선택
  → [Build Distributions]
  → Windows / Mac 체크
  → [Build]
  • 10회차에 만듭니다. 만든 뒤 다른 컴퓨터에서 실행되는지 꼭 확인하세요
  • 웹으로 올릴 때는 itch.io에 올리고 패들렛에는 링크만 붙입니다
  • 빌드 전에 renpy.notify 같은 디버깅 줄을 모두 지웁니다

⚠️ 이런 에러도 자주 납니다 에러

Sayer is not defined

y "안녕"이라고 썼는데 define y = Character(...)가 없는 경우입니다. 말하는 사람은 쓰기 전에 먼저 define 해야 합니다. 파일 맨 위에 모아두면 편합니다.

Could not find file 'images/…'

그림 파일이 그 경로에 없다는 뜻입니다. game/images 안에 정말 있는지, 확장자(.png / .jpg)와 대소문자가 같은지 확인하세요.

한글이 네모(□)로 보임

글꼴이 한글을 지원하지 않는 경우입니다. 한글 폰트 파일을 game/fonts에 넣고 gui.text_font를 그 파일로 바꾸세요. (12번 항목 참고)

대본을 고쳤는데 화면이 그대로

파일을 저장하지 않았거나, 게임 창에서 Shift+R로 새로고침하지 않은 경우입니다. 저장(Ctrl+S) 후 게임 창에서 Shift+R을 누르면 바로 반영됩니다.
