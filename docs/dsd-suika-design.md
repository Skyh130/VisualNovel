# English Suika CHESS — 게임 설계서 (DSD1)

> 지침서(`jls_dsd.md`)와 교재 목록 스크린샷(DSD1 세트)을 바탕으로 한 설계 문서.
> 구현 전 단계이며, 이 문서가 확정되면 MVP부터 개발한다.

## 0. 교재 구성 확인 (스크린샷 기준)

DSD1 세트는 총 9권이다. 지침서의 스테이지와 1:1로 매핑한다.

| 교재 | 지침서 스테이지 | 역할 |
|---|---|---|
| DSD1_CHESS Book 1 | Stage 1 (3-letter) | 어휘 |
| DSD1_CHESS Book 2 | Stage 2 (4~5 letter) | 어휘 |
| DSD1_CHESS Book 3 | Stage 3 (Sight words / 긴 단어) | 어휘 |
| 01. Not All Londoners Wear Hats | Stage 4 | 스토리 머지 |
| 02. The Day David Wasn't There | Stage 5 | 스토리 머지 |
| 03. How the Moon is Made of Cheese | Stage 6 | 스토리 머지 |
| 04. Andrew and the Babysitter + 05. Mr. Mistako | Stage 7 (Mix) | 스토리 혼합 |
| Speaking Tree 2A | Stage 8~10 | 말하기(음성 인식) |

**지침서에서 보완할 점**

1. 교재의 실제 단어·문장 목록은 내가 가지고 있지 않다. 단어/문장은 **데이터 파일(`stages.json`)로 분리**하고, 보호자가 교재를 보며 채운다. 코드는 데이터만 바꿔도 동작한다.
2. 교재 삽화·표지는 저작권이 있으므로 **사용하지 않는다.** 구슬 그림은 이모지 또는 직접 그린 SVG로 대체한다 (개인 학습용이라도 공개 배포 시 문제 방지).
3. 'Dream Tree' 인증서의 이름은 하드코딩하지 않고 **첫 실행 시 입력받아 저장**한다 (`localStorage`).
4. 브라우저(네이버 앱 등)에 따라 Web Speech API가 막혀 있을 수 있으므로 **음성 인식에는 항상 대체 입력(버튼)을 둔다.**

## 1. 핵심 플레이 규칙

| 항목 | 설계 |
|---|---|
| 화면 | 세로(모바일 우선), Canvas, 상자 1개, 상단에 "다음 구슬" 미리보기 |
| 낙하 | 터치/클릭한 x좌표(상자 폭 내로 클램프)에서 낙하. 낙하 후 0.6초 쿨다운 |
| 구슬 단계 | 스테이지마다 **8단계**(Lv1~Lv8). 시작 구슬은 Lv1~Lv3만 랜덤 등장, Lv4 이상은 병합으로만 생성 |
| 병합 | 같은 Lv 두 개 접촉 → 접촉점 중간에 Lv+1 생성. 마지막 Lv8끼리 닿으면 사라지고 보너스 점수 |
| 게임 오버 | 구슬이 위험선 위에 2초 이상 머무르면 종료 (낙하 직후 구슬은 1.5초 유예) |
| 클리어 | 스테이지 목표(점수 또는 최종 구슬 Lv8 1회 완성) 달성 → 다음 스테이지 해금 |
| 점수 | 병합 점수 = `Lv × 10`, 연쇄(1.5초 내 연속 병합) 시 콤보 배수 ×1.5, ×2 … 최대 ×3 |
| 목숨 | 없음. 게임 오버 시 해당 스테이지 재도전(저학년이므로 좌절 방지) |

### 학습과 연결되는 규칙 (수박 게임과의 차별점)

- **병합할 때마다** 해당 단어의 TTS 발음 + 구슬 위에 철자 표시 (눈·귀 동시 노출).
- 구슬은 **그림 + 영단어 라벨**을 함께 보여준다. Lv가 높을수록 그림 비중이 커지고 철자가 작아진다.
- **복습 보너스 구슬:** 이전 스테이지에서 자주 놓친 단어는 낮은 확률로 "★ 복습 구슬"로 등장. 병합하면 추가 점수.
- 스테이지 클리어 시 **학습 요약 화면**: 오늘 만난 단어 목록 + 소리 다시 듣기 버튼.

## 2. 스테이지별 상세

### Phase 1 — 어휘의 숲 (Stage 1~3, 조작: 터치)

| Stage | 진화 사슬 예시 | 물리/난이도 | 목표 |
|---|---|---|---|
| 1 | 3철자 단어 8개 (예: cat→dog→hat→…, 크기순이 아닌 **테마 순** 배열) | 기본 물리, 상자 폭 100% | 500점 |
| 2 | 4~5철자 단어 8개 (CHESS Book 2의 동사/명사) | 탄성 0.2→0.35 (더 튕김) | 900점 |
| 3 | 긴 단어 8개 (Londoners, Babysitter 류) | 상자 폭 90%로 축소, 최종 구슬 완성 시 +500 보너스 | 1,300점 |

> 단어 구슬은 길이가 달라도 **원 크기는 Lv로만 결정**한다. 긴 단어는 글자 크기를 자동 축소(`fitText`).

### Phase 2 — 스토리의 바다 (Stage 4~7, 조작: 터치)

사물 일러스트(이모지/SVG)로 진화 사슬을 만들고, **최종 구슬 완성 시 책 요약 문장**을 TTS로 읽고 팝업(영어 + 한글 해석, "따라 읽기" 선택 버튼).

| Stage | 책 | 진화 사슬 (제안) | 요약 문장 슬롯 |
|---|---|---|---|
| 4 | Londoners / Hats | 모자 → 털모자 → 우산 → 택시 → 2층 버스 → 타워브릿지 → 빅벤 | 보호자가 입력 |
| 5 | David | 연필 → 지우개 → 가방 → 책 → 책상 → 교실 → 데이비드 | 〃 |
| 6 | Moon / Cheese | 우유 → 작은 치즈 → 둥근 치즈 → 쥐 → 로켓 → 달 | 〃 |
| 7 | Andrew + Mr. Mistako (Mix) | 두 책의 아이템이 섞임. **낙하 속도 +30%**, 두 사슬이 동시에 존재 | 두 요약 문장 모두 |

> 사슬 길이는 8단계로 맞추되, 책 내용에 맞게 일부는 6~7단계도 허용(데이터에서 `levels` 길이로 결정).
> Stage 7은 서로 다른 사슬끼리는 병합되지 않으므로, 사슬 색상 테두리(파랑/주황)로 구분한다.

### Phase 3 — 스피킹 화산 (Stage 8~10, 조작: 음성)

**낙하 흐름:** 문장 카드 표시 → 마이크 버튼(자동 시작) → 인식 성공 → 구슬 낙하 위치는 **좌우 스와이프 또는 자동(상자 중앙)**.
(말하기와 위치 조준을 동시에 요구하면 2학년에게 과하므로, 조준은 말하기 **전에** 먼저 고정한다.)

| Stage | 문장 | 판정 | 비고 |
|---|---|---|---|
| 8 | 짧은 구 (2~4단어) "A big hat" | 단어 일치율 ≥ 60% | 힌트: 첫 시도 실패 시 TTS 모범 발음 재생 |
| 9 | 완전한 문장 (5~9단어) | 일치율 ≥ 70% | 제한 시간 8초 표시(초과 시 한 번 더 기회, 페널티 없음) |
| 10 | Speaking Tree 핵심 발표문 | 일치율 ≥ 70% | 상자 폭 80%, 구슬 크기 ×1.15 |

**음성 판정 로직**
1. 인식 결과와 목표 문장을 소문자화, 구두점 제거.
2. 단어 단위 비교(레벤슈타인 거리 ≤ 1 허용 → 발음 오인식 완화).
3. 일치율 = 맞은 단어 수 / 목표 단어 수. 임계값 이상이면 성공.
4. 실패 2회 → **"도움 받기"**: 문장을 따라 읽는 TTS 후 다시 도전, 3회 실패 시 **버튼으로 낙하 허용(점수 ×0.5)**. 학습 흐름이 끊기지 않게 한다.
5. 마이크 미지원/권한 거부 → 자동으로 터치 모드 + 안내 배너.

**Stage 10 엔딩:** Lv8 'Dream Tree' 완성 → 폭죽 파티클 + `DSD Master Certificate` (이름·날짜·획득 점수, 캔버스를 PNG로 저장 가능).

## 3. 기술 설계

### 스택
- 정적 웹앱, **빌드 도구 없음.** 기존 저장소(정적 HTML)와 같은 방식으로 `suika/` 폴더에 두면 그대로 호스팅 가능.
- Matter.js(CDN), Canvas 2D 렌더링, `speechSynthesis`(TTS), `SpeechRecognition`/`webkitSpeechRecognition`(음성).
- 음성 인식은 **HTTPS 필요.** Chrome/삼성 인터넷에서는 동작하나 일부 인앱 브라우저(네이버 앱 포함)는 미지원일 수 있다 → §1 대체 입력.

### 파일 구조
```
suika/
  index.html        # 화면 골격 (메뉴, 캔버스, 팝업)
  game.js           # 게임 루프, Matter.js 월드, 병합/게임오버 판정
  stages.json       # 스테이지 데이터 (아래 스키마)
  speech.js         # TTS, 음성 인식, 문장 일치율 판정
  ui.js             # 메뉴, 스테이지 선택, 팝업, 인증서
  store.js          # localStorage (진행도, 이름, 오답 단어)
  assets/           # 효과음, 직접 제작한 SVG
```

### 데이터 스키마 (`stages.json`)
```json
{
  "id": 4,
  "title": "Not All Londoners Wear Hats",
  "mode": "touch",
  "box": { "width": 0.95, "restitution": 0.2 },
  "dropSpeed": 1.0,
  "target": { "score": 1500, "finalLevel": 8 },
  "levels": [
    { "label": "hat",   "emoji": "🎩", "say": "hat" },
    { "label": "bus",   "emoji": "🚌", "say": "bus" }
  ],
  "summary": { "en": "…", "ko": "…" },
  "phrases": []
}
```
Phase 3은 `levels` 대신 `phrases: ["A big hat", …]`와 `mode: "voice"`를 사용한다.

### 물리 파라미터 (초기값, 플레이 테스트로 조정)
- 반지름: `r(Lv) = 18 × 1.28^(Lv-1)` px (상자 폭 360px 기준)
- 마찰 0.1, 반발 0.2(Stage 2는 0.35), 중력 scale 기본값
- 병합 판정: `collisionStart` 이벤트에서 같은 Lv 쌍 수집 → 프레임 끝에 일괄 처리(중복 병합 방지용 `merged` 플래그)
- 게임 오버: 구슬 `spawnedAt` 기준 유예 시간 이후 위험선 초과 누적 타이머

### 저장 데이터 (`localStorage`, 모든 접근 try/catch)
`playerName`, `unlockedStage`, `bestScore[stage]`, `missedWords{word: count}`, `settings{sound, tts, voice}`

## 4. 화면 흐름

```
시작(이름 입력, 최초 1회)
 └ 스테이지 선택 맵 (3개 Phase, 잠금/별 표시)
     └ 게임 화면 (HUD: 점수·목표·다음 구슬·🔊·⏸)
         ├ 병합 → 단어 TTS (Phase 3은 문장 카드)
         ├ 클리어 → 요약/단어 복습 → 다음 스테이지
         └ 게임 오버 → 재도전 / 맵으로
Stage 10 클리어 → 폭죽 → 인증서
```

UI 원칙(초2): 글자 최소 18px, 버튼 최소 48px, 한글 안내 + 영어 병기, 한 화면에 선택지 3개 이하, 실패해도 칭찬 문구("Good try!").

## 5. 개발 로드맵

| 단계 | 내용 | 완료 기준 |
|---|---|---|
| M1 | 물리 프로토타입: 상자·낙하·병합·게임오버 (Stage 1 원형 구슬만) | 한 판이 끝까지 플레이됨 |
| M2 | 데이터 기반 스테이지 로더 + 단어 라벨 + TTS | `stages.json` 수정만으로 단어 변경 |
| M3 | Phase 1·2 전체 + 점수/콤보/해금/저장 | Stage 1~7 플레이 가능 |
| M4 | 음성 인식 + 판정 + 대체 입력 (Stage 8) | 실기기(안드로이드)에서 인식 성공 |
| M5 | Stage 9~10, 인증서, 폭죽, 효과음, 복습 구슬 | 전체 플레이스루 |
| M6 | 실제 아이 플레이 테스트 → 난이도·임계값 조정 | 막힘 구간 없음 |

**가장 먼저 검증할 위험 요소:** (1) 사용 중인 브라우저에서 음성 인식 지원 여부, (2) 모바일에서 Matter.js 성능(구슬 40개 이상), (3) 한국어 TTS 환경에서 영어 음성 선택(`lang: 'en-US'` 보이스 확인).

## 6. 확인이 필요한 사항

1. 각 책의 단어/문장 목록 (또는 사진) — Stage 1~10 데이터 입력용
2. 플레이할 기기/브라우저 (안드로이드 + 삼성 인터넷/Chrome 가정)
3. 기존 `VisualNovel` 사이트에 메뉴로 붙일지, 별도 페이지로 둘지
4. Stage 8~10의 위치 조준 방식 (제안: 말하기 전에 조준 고정)
